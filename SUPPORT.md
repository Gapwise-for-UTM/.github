# Gapwise support

Use the channel that matches the problem so reports reach the right place without exposing sensitive information.

## Product help

For ordinary product questions, account help or feedback, contact **support@gapwise.ca**.

Before reporting an outage, check **[status.gapwise.ca](https://status.gapwise.ca)**.

## Bugs and feature requests

Open a GitHub issue in the repository that owns the behavior:

- Core web/PWA, timetable, gaps, routing, API: [`gapwise`](https://github.com/Gapwise-for-UofT/gapwise/issues)
- Native Android: [`android`](https://github.com/Gapwise-for-UofT/android/issues)
- Native iOS: [`ios`](https://github.com/Gapwise-for-UofT/ios/issues)
- AI/MCP integration: [`ai`](https://github.com/Gapwise-for-UofT/ai/issues)
- Campus data/provenance: [`data`](https://github.com/Gapwise-for-UofT/data/issues)
- Developer docs: [`docs`](https://github.com/Gapwise-for-UofT/docs/issues)
- Service status/monitoring: [`status`](https://github.com/Gapwise-for-UofT/status/issues)

## Security

Do not report vulnerabilities publicly. Email **security@gapwise.ca**.

## Developer documentation

See **[docs.gapwise.ca](https://docs.gapwise.ca)** for API, SDK, data, architecture and integration guidance.

## Privacy when asking for help

Please do not post credentials, auth tokens, private timetable contents, personal account data or other sensitive student information in public issues.

Gapwise is an independent student project and is not affiliated with, endorsed by, or an official service of the University of Toronto.
